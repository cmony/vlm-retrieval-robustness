# Reproducibility guide

This release separates three levels of reproduction.

## 1. Verify the published release without a GPU

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python scripts/verify_release.py
python -m unittest discover -s tests -v
```

The release gate checks the expected table row counts, the 30-test Holm family,
the 11 significant checkpoint contrasts, conditional transition-rate
identities, the 140 natural-distortion rank checkpoints, and the five paper
figures.

## 2. Rebuild the natural-distortion analysis from released ranks

The `artifacts/ranks/` directory contains the 140 compressed rank checkpoints
used by the corrected analysis. No model download or GPU is needed.

```bash
python analyze_results.py \
  --config configs/a100_full.yaml \
  --output-dir artifacts \
  --analysis-output-dir outputs/rebuilt-natural

python analyze_contrasts.py \
  --config configs/a100_full.yaml \
  --rank-root artifacts \
  --condition-aggregate outputs/rebuilt-natural/condition_aggregate.csv \
  --output outputs/rebuilt-natural/checkpoint_contrasts_i2t_r1.csv
```

Compare the rebuilt files with `results/natural/`. Stochastic Gaussian-noise
and cropping metrics are computed per repetition before averaging.

## 3. Re-run model inference

Download COCO 2017 validation images and captions into the paths specified in
`configs/a100_full.yaml`, then run:

```bash
python run_experiment.py --config configs/a100_full.yaml --dry-run
python smoke_models.py --config configs/a100_full.yaml
python run_experiment.py --config configs/a100_full.yaml
```

PyTorch is intentionally installed separately so that users can select a wheel
compatible with their CUDA environment. The reported run used Python 3.11,
PyTorch 2.11.0+cu128, Transformers 4.57.1, and an NVIDIA A100 80 GB GPU; see
`manifests/run_manifest.json` for the recorded environment.

## RoCOCO stress test

COCO `val2014` is required because the RoCOCO/Karpathy test split is different
from COCO 2017 validation. The script downloads the public RoCOCO annotations.

```bash
python scripts/rococo_only.py \
  --data_root rococo_run \
  --coco_val2014 data/val2014 \
  --models clip_vit_b32 clip_vit_b16 blip_base siglip_base \
  --perturbations same_concept diff_concept rand_voca danger \
  --image_attack --mix_method mix --lam 0.9 --seeds 1 10 100 \
  --results-output-dir outputs/rococo
```

The committed `results/rococo/` values are descriptive point estimates. The
large model-embedding cache is not committed and is regenerated by the command
above.

## Rebuild paper figures

```bash
python -m pip install -r requirements-analysis.txt
python scripts/regenerate_paper_figures.py
```

The generated PDF and PNG figures are written to `paper/figures/`.
